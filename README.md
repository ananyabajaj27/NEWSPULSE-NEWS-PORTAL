# 📰 NewsPulse – Online News Portal

NewsPulse is a simple, responsive, and user-friendly online news portal developed using HTML and CSS. It presents news from different categories in a clean and attractive layout.

## ✨ Features

- Attractive homepage with a featured news section
- Breaking News banner
- News categories: India, World, Sports, and Technology
- News cards with images, headings, and descriptions
- Navigation links to different sections
- Responsive layout for different screen sizes
- Clean and beginner-friendly design

## 🛠️ Technologies Used

- **HTML5** – To structure the website
- **CSS3** – To style the website and make it responsive

## 📂 Project Structure

```text
newspulse-news-portal/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the different news sections using the navigation links.
